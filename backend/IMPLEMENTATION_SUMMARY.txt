二、主要功能特性
----------------------------------------

1. 文档解析
   - 支持DOC/DOCX格式
   - 自动段落提取和清理
   - 最小段落长度过滤

2. 学生信息提取
   - 从文件名提取（学号-姓名格式）
   - 从文档内容提取
   - 学号解析（年级+班级）
   - 置信度评估

3. 文件存储
   - 本地文件系统存储
   - 按批次组织目录
   - 支持上传和结果文件

4. AI检测
   - 段落级检测
   - 论文级汇总
   - 规则引擎 + Distance Learning
   - 异常处理和降级

5. 异步处理
   - Celery任务队列
   - 批次并行处理
   - 进度跟踪
   - 错误处理

6. RESTful API
   - 文件上传（单批次/多文件）
   - 批次管理（CRUD）
   - 论文查询（按AI率排序）
   - 结果下载

7. 应用配置
   - CORS支持
   - 全局异常处理
   - 健康检查端点
   - 数据库自动初始化

三、技术栈
----------------------------------------
- FastAPI 0.104.1
- SQLAlchemy 2.0.23
- Celery 5.3.4
- python-docx 1.1.0
- Pydantic v2
- PostgreSQL 15
- Redis 7

四、API端点
----------------------------------------
POST   /api/v1/upload                    - 创建批次并上传文件
POST   /api/v1/batches/{id}/upload       - 上传文件到指定批次
GET    /api/v1/batches                   - 获取批次列表
GET    /api/v1/batches/{id}              - 获取批次详情
GET    /api/v1/batches/{id}/papers       - 获取批次论文（支持排序）
DELETE /api/v1/batches/{id}              - 删除批次
GET    /api/v1/papers                    - 获取论文列表
GET    /api/v1/papers/{id}               - 获取论文详情
GET    /api/v1/papers/{id}/result        - 下载检测结果
GET    /                                 - 根路径健康检查
GET    /health                           - 健康检查端点

五、下一步建议
----------------------------------------
1. 运行单元测试: pytest tests/ -v
2. 启动服务: uvicorn app.main:app --reload
3. 启动Celery: celery -A app.tasks.detection_tasks worker --loglevel=info
4. 访问API文档: http://localhost:8000/docs
5. 配置环境变量（.env文件）
6. 初始化数据库（自动执行）

六、注意事项
----------------------------------------
- 确保PostgreSQL和Redis服务已启动
- 配置DEEPSEEK_API_KEY用于Distance Learning
- 上传目录和结果目录会自动创建
- 所有文件操作都有异常处理
- 数据库表会在应用启动时自动创建
